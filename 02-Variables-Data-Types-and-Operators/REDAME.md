# Day 02 — Python Variables and Data Types

## What are Variables?
Variables are names used to refer to values in a Python program.

## Common data types
- `int`: Integer numbers
- `float`: Decimal numbers
- `str`: Text
- `bool`: True or False
- `list`: Ordered, mutable collection
- `tuple`: Ordered, immutable collection
- `set`: Collection of unique elements
- `dict`: Key-value pairs

## Important concepts
- Variables: Store and reference values.
- Naming Rules: Guidelines for naming variables.
- Dynamic Typing: Variables can refer to values of different types.
- `type()`: Checks an object's data type.
- Type Conversion: Converts values from one data type to another.

## Practical example
```python
# Create variables
name = "Gaurav"
age = 22
percentage = 74.13

# Display values
print(name)
print(age)
print(percentage)

# Check data types
print(type(name))
print(type(age))
print(type(percentage))
```
