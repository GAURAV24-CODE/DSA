# Day 01 — Introduction to Python

## What is Python?
Python is a high-level programming language used to give instructions to a computer.

## Common uses
- Data analysis
- Artificial intelligence
- Machine learning
- Automation
- Web development

## Important tools
- Python: runs Python programs.
- VS Code: editor for writing code.
- Jupyter Notebook: runs code in cells.
- REPL: allows interactive Python execution.

## First Python program
```python
print("Hello, World!")
```
